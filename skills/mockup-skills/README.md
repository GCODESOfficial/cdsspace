# CDS Space Mockup Skill Pack

Installed skills:

- brand-mockup-director
- blender-packaging-mockups
- cinema4d-redshift-mockups
- photoshop-brand-mockups

These skills provide repeatable workflows and local helper scripts. They do not install or license Blender, Maxon Cinema 4D, Adobe Photoshop, Redshift, or any desktop application.

The current runtime can use built-in image generation and the deterministic Python compositing helper. Actual Blender, Cinema 4D, Photoshop, or Adobe API execution requires those applications or connectors to be installed and available.
